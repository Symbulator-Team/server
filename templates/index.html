Circuit syntax reference

One element per line (or separated by :), fields separated by ,; node 0 is ground. See the documentation for a full walkthrough, or pick an example circuit above to see it in practice.

Elements

The first letter of an element's name selects its type. Element letters, element names and node names are not case-sensitive: R1 and r1 are the same resistor, and node A is node a.

ccapacitorname,n1,n2,value[,initial voltage]
linductorname,n1,n2,value[,initial current]

tideal transformername,n1,n2,N1,N2
oideal op-ampname,n+,n−,n_out
z y h g a btwo-port blockname,n1,n2

A value can be a number, a symbol (r_load, vin) or an expression — and an expression referring to another answer, like 2*v_2, makes a dependent (controlled) source. For FD and TR analysis give source values in the s-domain: 5/s for a 5 V step, 1 for a unit impulse.

SI prefixes

Write the apostrophe — 1'k — to say plainly that you mean an SI prefix. A bare 1k also works, but it is ambiguous (one kilo, or one times a variable named k?) and Symbulator will stop and ask.

'Mmega, ×1064.7'M

Case matters here. 'M is mega and 'm is milli — a factor of a billion apart. (Both 'k and 'K mean kilo.) Micro accepts either u or µ, so a value pasted from a datasheet works as typed. There is no prefix for exa: E is reserved for scientific notation, where 8E3 means 8000.

Numbers, constants and the imaginary unit

8000, 8000. and 8E3 all mean the same number; the last two are read as approximate rather than exact.

i, I, j and J all mean the imaginary unit and cannot be used as variable names — write 3j, 3*j or 3*i and you get the same thing, shown as 3j. Complex values belong to AC analysis only; in DC, FD and TR they are rejected. pi is π. Every other name you write is an ordinary variable, so Q, S and beta mean what you intend rather than something out of SymPy. Euler's number is exp(1).

In FD analysis s is the complex frequency and in TR t is time; elsewhere both are ordinary variables.

Expressions

In Evaluate and Solve you can refer to any answer with or without its underscore, in any capitalisation — so i_r1, ir1, i_R1 and IR1 all mean the current through r1. Answers are named v_<node> for node voltages and, per element, i_ current, v_ voltage drop, p_ power, s_ complex power, z_/r_ impedance seen by a source.

About input file (.cir) format

A plain text Input File can hold as many circuits as you like. Each one starts with its name in square brackets, followed by optional settings and then the element lines. Save it with a .cir extension. 

# comments start with a hash

[Problem 1 — divider]
analysis: dc
e1,1,0,20
r1,1,2,5'k
r2,2,0,15'k

[Problem 2 — RC transient]
analysis: tr
variables: v_2
e1,1,0,10/s
r1,1,2,2200
c1,2,0,4.7e-6

Settings are all optional: analysis (dc/ac/fd/tr), omega, variables, tool (th/er/port) with n1/n2/kind, and the expert-mode equation, condition and unknowns.

Run it offline, with no internet needed

This page needs a connection every time you use it. There is also an offline version that runs entirely inside your own browser — nothing is sent to any server — so once you've downloaded it, it keeps working with no internet at all, and your browser can install it like an ordinary app.

Download the offline version — one .zip, about 13 MB, works on Windows, macOS and Linux
How to run it

Unzip the download, then start it one of these ways — you only need to do this once per computer (see “install it as an app”, below):

SystemWhat to do
Windowsdouble-click start.bat
macOSdouble-click start.command (the first time, right-click it and choose “Open” — macOS blocks downloaded scripts by default)
Linuxopen a terminal in the folder and run sh start.sh

Any of these starts a small local web server and opens Symbulator Py in your browser automatically — leave that window open while you use it. Prefer to do it by hand? Open a terminal in the unzipped folder and run python3 -m http.server 8000, then visit http://localhost:8000/.

Install it as an app: once it's open in your browser, look for an “Install” icon in the address bar (or “Install Symbulator Py” / “Add to Home Screen” in the browser's menu). After installing, it opens like any other app, with no internet needed and no more running start scripts. Requires Python 3 only to run the one-time local server above — get it free from python.org if you don't have it; nothing else needs installing, since the maths engine itself (Python, SymPy and the symbulator package) runs inside your browser.

About Symbulator Py

Symbulator Py was created in August 2026 by Roberto Perez-Franco, realising a long-held wish to port Symbulator to Python and SymPy. Every version for the TI calculators — from the first in 1999 to version 8 in 2023 — was hand-written by the author. This Python version was written entirely by Claude, Anthropic's AI assistant, working to the author's design and instructions.

Symbulator Py is free and open-source software, released under the MIT licence: you may use, study, modify and share it, including commercially. The solver is published as the symbulator package on PyPI, and the project lives on GitHub. Contributions, bug reports and circuits that break it are all welcome.
