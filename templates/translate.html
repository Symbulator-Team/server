Help translate Symbulator

The app speaks thirteen languages. None of them has been checked by someone who speaks it.

Every translation in Symbulator was written by Claude, an AI, working from the English. They are careful, and they are unreviewed. If you read one of these languages, correcting one file is the most useful thing you can do for this program.

You do not need to know how Symbulator works, and you do not need to translate anything technical you are unsure of — leaving a phrase in English is more useful than a guess, because it tells us where the hard cases are.

The dictionaries

Each file is JSON: one line per phrase, as "key": "the translation". Edit the right-hand side only. English is the source and is generated from the app itself — read it, do not edit it.

What must survive your edit

Four things are machinery, not words. If one goes missing, that phrase breaks silently — so a checker compares them against the English and refuses a file that has lost one. You do not have to be careful, only aware:

  • %{name} — a slot the app fills in with a number or a name. Keep every one. Move it wherever your language's word order wants it.
  • <code>…</code> and other tags — keep them, and feel free to move them with the words they wrap.
  • id="…" inside a tag — the app looks elements up by these. Copy them exactly.
  • href="…" — the link's destination. Leave it.

What not to translate

The mathematics never changes. Variable names (v_2, i_r1), element letters, the decimal point, and unit symbols (V, Ω, Hz, s) stay exactly as they are in every language. A reader's answers have to match the printed tutorial's.

The rule for a label that contains a unit is: translate the word, keep the symbol — time (s) becomes Zeit (s), 时间（s）, समय (s).

Terms of art

Where a technical term has a settled word in your language, use it. Where it does not, a transliteration a student would recognise beats a coined translation nobody uses. Hindi and Bengali follow that rule already — components are transliterated (रेज़िस्टर, not प्रतिरोधक) while ordinary physics quantities keep their native word. Whether that was the right call is exactly the kind of thing a native speaker should overrule.

Sending it back

Email the edited file to translate@symbulator.com. Say which language it is, in case the filename does not survive the trip.

Or, if you would rather work in the open, open a pull request at github.com/Symbulator/server against the file under i18n/. Partial files are welcome either way: ten corrected lines are worth having.

Please say how you would like to be credited, or that you would rather not be.
